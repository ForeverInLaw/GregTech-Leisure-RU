# GregTech Leisure — Полный русский перевод

Полная качественная русская локализация для сборки **[GregTech Leisure (格雷科技休闲版)](https://github.com/nutant233/GTLCore)** (Minecraft 1.20.1 Forge).

---

## 🚀 Простая установка (для обычных игроков)

Установка занимает ровно одну минуту и не требует технических знаний:

### Шаг 1. Скачайте перевод
Перейдите на страницу релизов и скачайте архив:
👉 **[Скачать GregTech-Leisure-RU.zip (Последняя версия)](https://github.com/ForeverInLaw/GregTech-Leisure-RU/releases/latest)**

---

### Шаг 2. Откройте папку с вашей сборкой
В зависимости от того, какой лаунчер вы используете:

* **PrismLauncher / MultiMC**:
  1. Нажмите правой кнопкой мыши по вашей сборке `GregTech Leisure`.
  2. Выберите пункт **«Папка .minecraft»** (или *«Папка инстанса»* → папка *`minecraft`*).

* **CurseForge App**:
  1. Нажмите правой кнопкой мыши по профилю сборки (или нажмите кнопку с тремя точками `...`).
  2. Выберите **«Open Folder»** (Открыть папку).

* **TLauncher / Обычный лаунчер**:
  1. Откройте папку, где установлена сборка (обычно `%appdata%\.minecraft`).

---

### Шаг 3. Скопируйте файлы
1. Откройте скачанный архив **`GregTech-Leisure-RU-v1.0.zip`**.
2. Внутри архива лежат две папки: **`config`** и **`kubejs`**.
3. Просто перетащите обе эти папки в открытую папку сборки из Шага 2.
4. Если Windows спросит: *«Заменить файлы в папке назначения?»* — нажмите **«Да, заменить»**.

---

### Шаг 4. Готово!
Запустите игру:
1. Зайдите в **Настройки → Язык (Options → Language)**.
2. Выберите **Русский (Россия)**.
3. Готово! Все квесты, предметы, механизмы и книги теперь полностью на русском языке.

---

## 💡 Полезные советы по настройке для стабильной игры

1. **Рекомендуемая версия Java — Java 21**:
   * Для сборок GregTech на 1.20.1 настоятельно рекомендуется выбрать **Java 21** (например, [Eclipse Temurin 21](https://adoptium.net/temurin/releases/?version=21)) в настройках профиля лаунчера. Это обеспечивает современный сборщик мусора (GC) без микрофризов и защищает от утечек памяти.
2. **Выделение оперативной памяти (RAM)**:
   * Оптимально выделить **6–8 ГБ** (6144–8192 МБ). Выделять более 10–12 ГБ не рекомендуется во избежание долгих пауз GC.
3. **Первый запуск**:
   * Если вы только что установили сборку из CurseForge / PrismLauncher, запустите её один раз до главного меню, а затем закройте перед установкой перевода, чтобы игра создала все базовые конфигурации.

* 📜 **FTB Quests (100%)** — более 3 300 строк: все главы от каменного века и пара до космоса, квантовой физики и тира MAX.
* 🏭 **GTLCore (100%)** — кастомный кор-мод сборки: все многоблочные машины, корпуса, категории JEI и интерфейсы.
* ⚙️ **KubeJS (100%)** — кастомные предметы, сверххрональные микросхемы, катушки, сингулярности и подсказки.
* ⚡ **GTMThings (100%)** — беспроводная передача энергии, оптические люки и терминалы.
* 🚀 **Ad Astra (Astrodux)** — вся книга-руководство астронавта (ракеты, скафандры, Луна, Марс, станции).
* 🔧 **Оверрайды модов** — перевод строк для `mae2`, `ad_astra_rocketed`, `shrink`, `laserio`, `usclb`, `ftbbackups`, `ftbessentials`.

## 🛠️ Для разработчиков и авторов сборок

Если вы хотите вносить изменения в перевод или собирать проект из исходников:

### Структура репозитория
* `quests/` — итоговый файл квестов `ru_ru.json`
* `assets/` — ресурсы и оверлеи для `kubejs/assets/`
* `tools/` — пайплайн сборки:
  * `glossary.json` — эталонный терминологический глоссарий GTCEu Modern
  * `build_all.js` — слияние частей, валидация и автоматическая синхронизация
  * `sync.js` — копирование перевода напрямую в инстанс PrismLauncher
  * `package.js` — сборка готового `.zip` архива релиза
  * `audit_translations.js` — аудит на целостность и спецсимволы

### Сборка и проверка
```bash
# Собрать и проверить все файлы
node tools/build_all.js

# Собрать zip-архив релиза
node tools/package.js
```
