# Опциональные QOL-моды для GregTech Leisure

В этот набор входят два дополнительных мода, значительно повышающих удобство игры (QoL) на поздних этапах:
1. **GTLAdditions** (v3.3.1Custom) — расширение для GregTech Leisure, добавляющее **Super ME Pattern Buffer** (автоматическое переключение микросхем 1–24 в рецептах автокрафта), распределённые облачные вычисления (Cloud Computation) и уникальные мега-структуры эндгейма (*Кузница Антихриста*, *Небесная печь Багуа*, *Матрица создания пространственного фокуса*).
2. **Stargate Journey** (v0.6.44) — мод на «Звёздные врата» (Stargate), позволяющий мгновенно путешествовать между Землёй, космическими станциями и удалёнными планетами (Луна, Марс, Венера, Гласио и др.) через набор адреса на наборном устройстве (DHD), без необходимости каждый раз запускать ракету Ad Astra.

## 🚀 Установка опциональных модов
Если вы хотите играть с этими модами:
1. Скачайте архив **`GregTech-Leisure-RU-with-QOL-Mods-v1.0.zip`** со страницы релизов.
2. Распакуйте папки `config`, `kubejs` и `mods` в папку вашей сборки с заменой.
3. Готово! Все элементы Звёздных врат и супер-буферов переведены на русский язык.
